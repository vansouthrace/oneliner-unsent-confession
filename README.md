# Unsent: The Micro-Confession Sprint — make.fun entry

A micro-confession in exactly two parts: a To: line and the unsent message itself, in 260 characters or fewer.

> To: my old landlord
> I never told you the leak in the bathroom was me testing whether the ceiling could hold a small indoor waterfall, and I am still sorry about the paint.
